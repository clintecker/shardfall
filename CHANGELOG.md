## [0.11.0] - 2026-11-20

The first release from this repository. The game moved out of a single hand-edited HTML file
and into source control, with tests.

### Changed

- **Announcements no longer cover the board.** "Your move", "Rivals moving", "City captured"
  and friends used to sweep across the middle of the screen in a full-width band. They are
  now a compact plate that drops in under the top bar. The coach tip, which shares that
  spot, steps aside while one is showing.
- The source is split into 24 commented files under `src/` and formatted with Prettier. It
  was previously one 190 kB file with very long lines. Behavior is unchanged apart from the
  entries on this list.
- The published single-file game is now generated by `npm run build` instead of being edited
  directly.

### Fixed

- **Every side now really does start with an ore ridge.** Map generation promises each
  capital one ore ridge among its neighbors, then carves a road from the capital to the
  middle of the board. One time in eight, the ridge was placed on the first tile of that
  road and flattened by it, leaving that side with no ore next to its capital for the whole
  game. The ridge is now kept off the road. Found by the new map-generation tests.

### Added

- A test suite that runs without a browser: every rule against the numbers in the docs, 108
  generated maps checked for fairness, and 40 complete AI-versus-AI games audited turn by
  turn.
- A browser smoke test (`npm run test:e2e`) that boots the real WebGL game from both the
  source page and the built page.
- `npm run check`: static checks for the things that break a no-bundler codebase (a script
  nobody loads, two files declaring the same name, an unpinned CDN URL).
- `npm run balance`: win rates per culture over hundreds of simulated games.
- `npm run screenshots`: regenerates every image in the docs from the running game.
- A zero-dependency dev server that serves three.js locally, so development works offline.
- Documentation: rules, architecture, rendering, world guide, development guide, roadmap.
- Continuous integration on GitHub Actions.

### Known issues

- The Verdant Lattice wins about half of AI-only four-way games. See
  [docs/ROADMAP.md](docs/ROADMAP.md#balance).

## 0.1.0 to 0.10.0: the artifact era

Before this repository existed, Shardfall was built over ten published revisions of a
single Claude artifact, each one a response to a round of feedback. Those revisions were not
tagged or dated individually, so they are summarized here as milestones, oldest first.

1. **A playable game.** A turn-based conquest for one commander: four cultures, fog of war,
   outposts to capture, cities to grow, a twelve-technology tree, six unit types, rival AI
   and a thirty-turn clock.
2. **Better graphics**, twice. The first visual pass was judged, accurately, to suck.
3. **A board you can turn.** Free rotation of the board around its vertical axis, with
   proper 3D terrain and characters to make it worth turning.
4. **The WebGL rebuild.** Rendering moved to three.js: physically based materials, real
   shadows, HDR bloom and a neon city under the board.
5. **Post-processing.** Depth of field, ambient occlusion from the depth buffer, lens
   streaks, filmic tone mapping and a color grade, all in one final pass.
6. **Characters and transitions.** Units redesigned with per-culture silhouettes and
   animated entirely in the vertex shader. Fog of war lifts with an animation, and so does
   every other change of state. The backdrop gained air traffic, dogfights, searchlights and
   lightning.
7. **Homelands.** Each culture got its own biome: ground, flora, rock, liquid and light.
8. **Skies, layouts and a new interface.** Five atmospheres with their own weather, four
   terrain presets, and a rebuilt interface: full-screen board, action bar, minimap, coach
   tips, tooltips, attack forecasts, undo, keyboard shortcuts and a settings menu.

Along the way an army supply cap was added, after an automated playthrough showed that
whoever trained the most Troopers won.

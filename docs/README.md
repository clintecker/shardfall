# Shardfall documentation

Start with whichever of these matches why you are here.

| I want to...                              | Read                               |
| ----------------------------------------- | ---------------------------------- |
| Play well                                 | [GAMEPLAY.md](GAMEPLAY.md)         |
| Know who the Null Choir are               | [WORLD.md](WORLD.md)               |
| Understand the code before I change it    | [ARCHITECTURE.md](ARCHITECTURE.md) |
| Understand how any of this is being drawn | [RENDERING.md](RENDERING.md)       |
| Add a unit, fix a bug, ship a build       | [DEVELOPMENT.md](DEVELOPMENT.md)   |
| See what is broken and what is planned    | [ROADMAP.md](ROADMAP.md)           |
| See what changed                          | [CHANGELOG.md](../CHANGELOG.md)    |

The images in [`media/`](media) are generated from the running game by
`npm run screenshots`. Do not edit them by hand; change the game and regenerate.

Every file under `src/` also opens with a comment saying what it is for, and those comments
are the most detailed map of the code there is.
